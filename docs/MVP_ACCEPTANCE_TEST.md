# MVP 验收测试

## 环境

- Windows 教学目标电脑
- Unity 编辑器版本 `2022.3.62f3c1`
- 断开网络后仍可运行
- 使用教师已批准的 Fe 实验配置与参考数据

## 自动化验收

### EditMode

- [ ] 合法步骤能够按顺序推进至完成
- [ ] 跳步、重复命令和非法状态转换被拒绝
- [ ] 参数边界、单位和组合约束正确校验
- [ ] 线性拟合与教师参考结果一致
- [ ] 无效点数、退化数据和非有限数值返回明确错误
- [ ] 样品浓度及稀释换算与教师参考结果一致
- [ ] 配置版本、重复 ID、无效引用和草稿状态被正确处理

### PlayMode

- [ ] 从主菜单进入并完成一条 Fe 测定流程
- [ ] 页面状态与流程状态保持一致
- [ ] 错误提示包含原因和恢复建议
- [ ] 暂停、恢复和重置行为正确
- [ ] 记录保存后可再次读取并展示
- [ ] 重复点击不会产生重复测量或重复记录

## 手工验收

- [ ] Windows 发行包在无网络环境启动
- [ ] 首次启动和常规交互达到需求中的响应目标
- [ ] 常用教学分辨率下文字、按钮和图表可读
- [ ] 状态不只依靠颜色表达
- [ ] 文件不可写时不丢失当前实验且允许重试
- [ ] 损坏配置和记录不会导致静默错误或错误结论
- [ ] 日志与记录不包含未经授权的人员和实验室敏感信息
