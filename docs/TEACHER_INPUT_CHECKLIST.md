# 教师资料与科学审核清单

在实现真实实验规则前，请由课程教师或实验负责人提供并审核以下资料。资料可分批提供，但每项必须标明来源、版本和审核人。

## 仪器与界面

- [ ] 仪器厂商、完整型号和允许公开的外观信息
- [ ] 铭牌照片或型号证明；上传仓库前完成编号和人员信息脱敏
- [ ] 开机、状态检查、方法设置、测量、结果和关机界面截图
- [ ] 进样管、蠕动泵、炬管、等离子体等教学部件说明
- [ ] 可用于软件的照片和音频授权范围

## SOP 与实验流程

- [ ] ICP-OES 完整操作 SOP 及版本日期
- [ ] Fe 测定实验的逐步操作流程
- [ ] 每一步的前置条件、完成条件和允许操作
- [ ] 暂停、重测、冲洗、关机和异常恢复流程
- [ ] 安全注意事项及必须展示的警告

## 参数与单位

- [ ] 参数名称、单位、默认值、最小值、最大值和输入精度
- [ ] 参数之间的组合约束
- [ ] 仪器状态与参数可修改条件
- [ ] 显示名称和教师期望的解释文本

## 标准曲线与浓度计算

- [ ] Fe 标准溶液浓度、单位、配制信息和有效位数
- [ ] 对应测量数据或可复现的仿真生成规则
- [ ] 回归模型、是否使用截距、权重和异常点处理规则
- [ ] 拟合质量指标及合格阈值
- [ ] 样品稀释、体积、质量和最终浓度换算公式
- [ ] 结果舍入、检出限/定量限和超范围处理方式
- [ ] 至少一组完整输入与参考输出

## 错误与教学反馈

- [ ] 常见错误操作及判断条件
- [ ] 每种错误的学生提示、原因和恢复步骤
- [ ] 哪些错误阻止继续，哪些仅警告
- [ ] 教师希望记录或评分的关键操作

## 验收签署

```text
资料名称：
来源/文档版本：
提供日期：
审核人：
允许进入软件：是 / 否
允许进入私有仓库：是 / 否
备注：
```

未经审核的内容必须保持 `reviewStatus: "draft"`，不得用于发布构建或教学结论。
